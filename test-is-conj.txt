
==Introduction==

===Principal part spec===
The full spec format after {{tl|is-conj}} is one or more ''indicator specs'', separated by a dot, i.e. {{cd|.}}. The first indicator spec, called the ''principal part spec'', is mandatory (except in the middle-voice spec) and has a special format. In particular, its full format is
* {{cd|CLASS;PRES_IND_SG#PRES_IND_PL,PRES_SUBJ_SG#PRES_SUBJ_PL\PAST_IND_SG#PAST_IND_PL,PAST_SUBJ_SG#PAST_SUBJ_PL/PAST_PART,SUPINE}}
This spec contains two sections, the first specifying the verb class (which is mandatory except in the middle-voice spec) and the second giving all the principal parts. All punctuation characters other than underscore are part of the format and need to be present in order to separate one part of the spec from another; but if some parts are omitted, the separating punctuation can usually be omitted as well (see below for the specifics). Note specifically:
# {{cd|CLASS}} specifies the verb class and is either {{cd|s}} (strong) or {{cd|w1}} ... {{cd|w4}} (weak-1 through weak-4), or two or more classes separated by a colon (e.g. {{cd|s:w2}}), if a verb can be conjugated more than one way. Qualifiers in brackets can be specified after a class, e.g. {{cd|w2:s[poetic]}}, meaning "weak-2 or {{q|poetic}} strong". These qualifiers appear in the inflection table title rather than as footnotes on individual forms.
# If the class specifies a weak verb, defaults are provided for all principal parts, but the past participle must always be specified, often as {{cd|+}} to select the default, or {{cd|-}} if there is no past participle. For example, {{m|is|horfa||to look, to watch}} uses {{cd|w3/-}} to indicate that there is no past participle. (As shown here, when principal parts are omitted, the corresponding separators can be omitted as well.)
# Note that the supine derives its ''form'' from the past participle but not its existence. If a past participle is specified, the supine will be derived from it. However, if there is no past participle, the supine is still assumed to exist unless specifically given as {{cd|-}}. If the supine is left unspecified, or is specified as {{cd|+}}, it will be derived from the form that the default past participle would take if it existed. For example, for {{m|is|horfa}}, the default past participle is ''horfður'', and the supine will be formed from this: specifically from the strong nominative/accusative neuter singular, producing ''horft''.
# If the class specifies a strong verb, the standard principal parts must at a minimum be given, i.e. past indicative singular, past indicative plural and past participle. For example, {{m|is|drífa||to drive, to drift}} uses the principal part spec {{cd|s\dreif#drifum/drifinn}}. If there is no past participle, the supine must be specified. For example, {{m|is|skína||to shine}} uses {{cd|s\skein#skinum/-,skinið}}.
# Singular principal parts should use the first-person singular, and plural principal parts should use the first-person plural (even in impersonal verbs; e.g. strong verbs need the past indicative 1p specified, and for impersonal strong verbs like ''kala'' the corresponding form ''kólum'' is a ghost form, but correctly forms subjunctive ''kæli''). The past participle should use the standard adjective lemma format (i.e. strong nominative masculine singular).
# If a given part has more than one possibility, separate them with a colon, i.e. {{cd|:}}. Any given principal part can be followed by a footnote in square brackets, which will be applied to all forms derived from that principal part (footnotes are given lowercase and without a following period, and will be converted to sentence form by uppercasing the first character and adding a final period/full stop).
# Some of the principal parts and other indicators can optionally be followed by ''modifier specs'' in parentheses. In particular:
## Any past indicative principal part (singular or plural) can be followed by an ''umlaut spec'', controlling whether and how umlaut occurs in the corresponding past subjunctive forms, which can be one (or more) of the following:
### The value {{cd|^}}, which indicates that the past subjunctive stem should be derived from the given past indicative form by applying ''umlaut'' (aka ''i-mutation'') to the last vowel of the indicative stem, according to the normal rules for umlaut. For example, {{m|is|segja||to say}} uses the principal part spec {{cd|w3\sagði(^)/+}}, giving the past indicative as ''sagði'' and specifying that the subjunctive should be derived by applying umlaut to the indicative, producing ''segði''. A more complex example is {{m|is|duga||to suffice; to serve, to avail}}, which uses {{cd|w3:w4\dugði(^):dugaði/-}}. This indicates that the verb can be conjugated either as a weak-3 verb (present indicative ''dugi, dugir, dugir''; imperative ''dug''; etc.) or weak-4 verb (present indicative ''duga, dugar, dugar''; imperative ''duga''; etc.). The past {{cd|dugði:dugaði}} is in fact the default, but we want to specify that the subjunctive derived from ''dugði'' is umlauted ''dygði'' while the subjunctive derived from ''dugaði'' is un-umlauted ''dugaði''.
### The value {{cd|-^}}, which indicates that umlaut should not take place (used when umlaut is the default, as in strong, weak-1 and weak-2 verbs).
### A vowel such as {{cd|y}}, indicating that the given vowel should be used as the umlaut vowel. For example, {{m|is|þora||to dare}} uses the principal part spec {{cd|w3\+(y)/-}}, where {{cd|+}} requests the default form ''þorði'' and {{cd|(y)}} specifies that the subjunctive is ''þyrði'' (the default umlaut for ''o'' is ''e'', not ''y'').
### Two or more such specs separated by a colon, optionally with footnotes attached in square brackets.
## The past participle can be followed by an adjective spec of the same format as is normal for adjectives (see the documentation of {{tl|is-adecl}}), except that no specs are mandatory (in particular, the comparative does not need to be given). For example, for {{m|is|rýja||to shear}}, which can be conjugated either as a weak-3 or (in archaic usage) as a weak-1 verb, the spec {{cd|w3:w1;rýi:rý[archaic and no longer recommended]\rúði(-^)/rúinn:rúður(suppress:r*)}} can be used. Here, the past participle can be either ''rúinn'' or ''rúður'', but forms of the latter with an ending beginning with ''r'' are missing (i.e. strong dative feminine singular ''*rúðri'', strong genitive feminine singular ''*rúðrar'', and strong genitive plural ''*rúðra''). The {{cd|suppress:r*}} spec is one of the specs that can be given in {{tl|is-adecl}}, and causes the forms for endings beginning with ''r'' to be omitted. (This example also shows the use of {{cd|-^}} to turn off umlaut. Umlaut in the past subjunctive is the default for weak-1 (but not weak-3) adjectives, so by specifying the class as both weak-3 and weak-1 we'll wrongly get both umlauted and un-umlauted past subjunctives unless we explicitly turn off umlaut.)
## The {{cd|mid}} indicator can be followed by a full conjugation spec in parentheses. This is discussed in more detail below.

To omit only the present, write
* {{cd|CLASS\PAST_SPEC/PP,SUP}}
where {{cd|PAST_SPEC}} is {{cd|PAST_IND_SG#PAST_IND_PL,PAST_SUBJ_SG#PAST_SUBJ_PL}} or some subset.

To omit only the past, write
* {{cd|CLASS;PRES_SPEC/PP,SUP}}
where {{cd|PRES_SPEC}} is {{cd|PRES_IND_SG#PRES_IND_PL,PRES_SUBJ_SG#PRES_SUBJ_PL}} or some subset.

To omit both present and past (but not past part+supine), write
* {{cd|CLASS/PP,SUP}}

To omit only the past part+supine, write
* {{cd|CLASS;PRESSPEC\PASTSPEC}}

To omit the present and past part+supine, write
* {{cd|CLASS\PASTSPEC}}

To omit the past and past part+supine, write
* {{cd|CLASS;PRESSPEC}}

To omit the present, past and past part+supine, write
* {{cd|CLASS}}

In other words, {{cd|CLASS}} is required, and for each of the major components of the principal part spec (present, past, and past participle/supine) that is included, also include the preceding punctuation character, which is different for each of the major components.

Parts of an the present or past components can also be omitted; specifically, anything including and after a {{cd|#}} (specifying the plural) can simply be omitted, and likewise the comma and following subjunctive spec. To specify e.g. the plural while defaulting the singular, or the subjunctive while defaulting the indicative, use {{cd|+}} for the defaulted part(s).

===Other indicators===
It is mandatory to specify whether the middle is present. This is done using {{cd|mid}} (middle voice exists and is conjugated like the active), {{cd|-mid}} (no middle voice) or {{cd|mid(...)}} to explicitly specify how to conjugate the middle. The spec inside is like a normal active-voice spec except the nothing is mandatory (that is, the principal part spec can be omitted entirely, and there is of course no need or possibility of specifying {{cd|mid}} or {{cd|-mid}}). For example, use {{cd|mid(impers)}} to specify an impersonal middle voice; {{cd|mid(-impers)}} to specify that the middle voice is not impersonal, if the active is impersonal; use {{cd|mid(-qform.+imp)}} to specify that question forms are missing but imperatives are present (both of these are the opposite the defaults for these forms); etc. If you do specify the principal part spec, {{cd|CLASS}} is not required, but at least one of {{cd|;}}, {{cd|\}} or {{cd|/}} must be present so that the module knows that a principal part spec is being given.

===Defaults===
The defaults are as follows:
# The present indicative singular is derived from the infinitive stem. Strong verbs have i-mutation (umlaut) in the present indicative singular. Strong verbs with breaking of -e- to -ja- in the infinitive restore this to -e- (and do not umlaut it to i).
# The present indicative plural is likewise derived from the infinitive stem (''NOT'' from the present indicative singular).
# The present subjunctive singular is derived from the present indicative plural (particularly the 3p form, because it shows interpolated /j/ when appropriate? The 2p form doesn't have /j/, and the 1p form may have u-mutation).
# The present subjunctive plural is derived from the present subjunctive singular. (FIXME: make sure this latter default is correct)
# The past indicative singular is a principal part in strong verbs. In weak verbs, it comes from the infinitive or present (FIXME, clarify how), often with reverse i-mutation (FIXME, clarify when).
# The past indicative plural is a principal part in strong verbs. In weak verbs, it is presumably derived from the past indicative singular (FIXME, verify this).
# The past subjunctive singular is derived from the past indicative plural, with i-mutation in most circumstances (FIXME, clarify when i-mutation isn't the default).
# The past subjunctive plural is derived from the past subjunctive singular (FIXME, verify this).
# The present particle is derived from the infinitive (FIXME: or the 3p present indicative? are they always the same?) by adding -andi, or by adding -ndi if the infinitive already ends in -a.
# The past participle is a principal part in strong verbs. In weak verbs, it is presumably derived from the past indicative singular or plural (FIXME, clarify how).
# The supine is derived from the neuter singular nom/acc of the past participle (FIXME, verify this). Many verbs, however, are lacking the past participle (but always (?) have a supine); if the past participle is missing, the supine is derived from what the past participle would be if present.
# The bare 2s imperative is derived from the infinitive by dropping final -a (if present) and preceding -j-/-v- (if present), except in weak-4 verbs, where the imperative ends in -a and is identical to the infinitive.
# The 2p imperative is always the same as the pres indic 2p.
# The joined 2s imperative is taken from directly from the bare imperative (after processing individual-form overrides) by adding -ðu, which assimilates to a preceding consonant according to the dental assimilation rules outlined on pages 82-83 of Einarsson. These are the same rules used for forming the weak past and past participle, and in case the bare imperative ends in one of the ambiguous consonants or consonant clusters mentioned by Einarsson (rr, rn, vowel+l, ld, nd, ll, nn), where more than one possibility exists, the 1s past indic is examined, and if it is weak (ends in -i), the preceding consonant cluster is used. (This correctly handles variations like ''velldu'' from vella vs. ''skelltu'' from skella.) If the imperative ends in an ambiguous cluster and the past is strong, we follow Einarsson's "usually" statements by using -d after vowel+l, -t after ld/nd/ll/nn, and throwing an error for rr (where either -ð or -t is found) and rn (where either -d or -t is found). If there is no bare imperative (after processing individual-form overrides) but -imp wasn't used, we use the 1s past indic directly if it is weak (ends in -i), by replacing -i with -u; this correctly handles e.g. verbs like æja with past ''áði'', no bare imperative, joined 2s imp ''áðu'' and 2p imp ''æið'' (taken from pres indic 2p ''æið''). Otherwise if there is no bare imperative, -imp wasn't given and the 1s past indic is strong, we throw an error.
# The active-voice question forms (second-person only but which exist in singular and plural, present and past and indicative and subjunctive) are derived from the corresponding "statement" forms and are assumed to exist by default except in impersonal verbs.
# The middle-voice question forms are similar (second-person only, present and past, indicative and subjunctive, but exist only in the singular), are derived from the corresponding "statement" forms and are assumed to exist by default except in impersonal verbs.
# Whether there is a middle voice needs to be specified. The middle voice, as mentioned, is assumed to have question forms except in impersonal verbs, but is assumed not to have imperatives. If imperatives are indicated with {{cd|+imp}}, they are assumed not to have the bare 2s form; that must be separately indicated using {{cd|imp2s:+}}.
# The middle voice derives its defaults from the active except that (a) there is no imperative by default and (b) generation of the middle voice happens before individual-form override processing. They can be changed if necessary by placing a spec in parens following the word {{cd|mid}}, e.g. {{cd|+imp}} if there is an imperative (as mentioned above, there is normally no bare 2s middle imperative, and {{cd|+imp}} does not select it); {{cd|-impers}} if the active voice is impersonal but not the middle, as in {{m|is|rökkva||to become dusk}}; or {{cd|-qform}} . Footnotes can be given in brackets are {{cd|mid}}; they go before any spec in parens if present, e.g. {{cd|mid[rare](-impers)}}.
# Note that if middle voice forms are explicitly given, they should be given in the corresponding active form, and the middle forms will be automatically derived.
#
